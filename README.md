# PopStarPixelDeskpets

两个像素桌宠的完整制作档案：Drop Dead Pixel 与 Fearless Fox。

| Drop Dead Pixel | Fearless Fox |
| --- | --- |
| ![Drop Dead](pets/drop-dead/previews/idle.gif) | ![Fearless Fox](pets/fearless-fox/previews/idle.gif) |

## 内容

- 每个桌宠均包含九组动画与十六个视线方向，共73帧。
- 透明PNG精灵图：1536×2288，8列11行，每格192×208，Pets v2。
- 源图、参考布局、生成提示词、帧图、GIF/MP4预览、验证与方向盲测报告。
- Drop Dead：蓝色短裙、粉色耳机与吉他。
- Fearless Fox：用户最终选定的直发、狐系蓝眼、大头短腿与金色流苏裙版本。

## 查看与使用

打开各宠物目录下 `previews/all-states.gif` 或MP4查看整套动画；`spritesheet.png`是最终精灵图，`brief.md`记录制作说明，`qa/`保存验证报告。

本仓库保存美术与动画制作素材，不是可独立安装运行的桌面应用。宠物库中的成品由ChatGPT Pets创建；精灵图可供兼容v2格式的工具使用。

## 验证

最终精灵图通过结构、透明背景、动作与方向检查。具体警告与人工复核结论见各自QA报告；SHA256见 `checksums.json`。
